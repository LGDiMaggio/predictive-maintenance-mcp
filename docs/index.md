# Predictive Maintenance MCP Server

**Open-source AI + vibration diagnostics toolkit** for engineers and developers.

Turn raw machinery signals into **actionable maintenance decisions** using MCP-compatible assistants (Claude, ChatGPT, and local agents).

[Get Started on GitHub](https://github.com/LGDiMaggio/predictive-maintenance-mcp){: .btn }

---

## Why teams adopt this project

- **Faster fault triage** with guided diagnostics for bearings and gears
- **Actionable evidence** via FFT, envelope analysis, and ISO 20816 assessments
- **Production-friendly outputs** using shareable interactive HTML reports
- **Privacy-first architecture** (local files, local processing)
- **Extensible MCP server** for custom tools, workflows, and datasets

## Core capabilities

- Multi-format signal ingestion (CSV, MAT, WAV, NPY, Parquet)
- Bearing-fault-focused envelope analysis
- ISO 20816-3 severity evaluation
- ML anomaly detection on healthy baselines
- Manual parsing + bearing catalog lookup
- Copilot-style workflow skills

## Who this is for

### Reliability / Maintenance Engineers
Use natural language to:
- screen machine health,
- identify likely fault families,
- generate reports for operations and management.

### AI / Software Developers
Use this repository to:
- learn MCP tool design,
- integrate domain tooling with LLMs,
- build reusable industrial copilots.
