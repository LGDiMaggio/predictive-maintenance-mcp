What Can It Do

Upload a Signal, Get a Professional Diagnosis

The AI calls 48 specialized analysis tools running locally on your machine. Your data never leaves your infrastructure.

💬 “Is this bearing healthy?”
Loads the signal, runs spectral analysis, checks for fault patterns, classifies severity per ISO 20816-3.
💬 “Generate a full diagnostic report”
Produces an interactive HTML report with charts, fault markers, and severity assessment ready for your supervisor.
💬 “Extract specs from this pump manual and diagnose the signal”
Reads the equipment manual, looks up the bearing model, calculates expected fault frequencies, matches them against the signal.
💬 “Train an anomaly detector on my healthy baselines”
Trains a machine learning model on normal data, scores new signals, highlights outliers with PCA visualization.

Capabilities

Professional-Grade Analysis Tools

Accessible through any MCP-compatible AI assistant.

📊

FFT Spectrum Analysis

Frequency-domain decomposition with automatic peak detection, harmonic identification, and dB-normalized visualization.

🔍

Envelope Analysis

Bearing-fault-focused demodulation. Reveals characteristic defect frequencies (BPFO, BPFI, BSF, FTF) hidden in raw signals.

📏

ISO 20816-3 Assessment

Automated vibration severity evaluation per international standards, with 4 severity zones and hypothesis-based confirmation.

🤖

ML Anomaly Detection

Train on healthy baselines, detect anomalies in new signals. OneClassSVM & LocalOutlierFactor with automatic feature extraction.

📄

Interactive Reports

HTML reports with Plotly charts and structured Word diagnostics. 6 report types for ops teams and management.

📖

Document Search (RAG)

Semantic search over equipment manuals and bearing catalogs. Extract specs from PDFs and match to signals automatically.

📈

Prognostics & RUL

Remaining Useful Life estimation and trend analysis with confidence intervals — ISO 13374 Block 5. Move from reactive to predictive decisions.

🧠

Decision Intelligence

Evidence-based diagnosis pipeline, alert triage, and contextual maintenance recommendations built on the ISO 13374 Block 6 advisory layer.

Architecture

Privacy-First, Standards-Based Design

Raw vibration data never leaves your machine. Only computed results flow to the LLM.

YOU (natural language) | v LLM (Claude / GPT / Ollama) | Model Context Protocol v +----------------------------------+ | Predictive Maintenance MCP | | | | signal_acquisition [Block 1] | | signal_processing [Block 2] | | diagnostics [Block 3-4]| | prognostics [Block 5] | | decision_support [Block 6] | +----------------------------------+ | v YOUR DATA (always local) signals · manuals · models

🔒 Privacy-First

Raw vibration data processed entirely on your machine. Only computed results (severity scores, fault classifications) flow to the LLM.

🌐 LLM-Agnostic

Works with Claude, ChatGPT, Microsoft Copilot Studio, or any MCP-compatible client. Use Ollama for fully air-gapped deployments.

🏗 ISO 13374 Six-Block Architecture

Each sub-package maps to an ISO 13374 block: signal_acquisition (B1), signal_processing (B2), diagnostics (B3-4), prognostics (B5), decision_support (B6).

🧩 Extensible by Design

Use only the tools you need, extend with your own. Plugin architecture supports custom signal processors, diagnostics, and report formats.
